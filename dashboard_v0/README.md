# An Experimental Version of TalkTuner with More Functionality
This interface shares the same backend as dashboard_v1 but expose more functionality, including intervention exploration, change in user model visualization, word/token-level user model (how each token in the input affects the LLM's model of user), word/token-level user model intervention (how each token in the LLM's output changed if an intervention on a user attribute is intervened).
