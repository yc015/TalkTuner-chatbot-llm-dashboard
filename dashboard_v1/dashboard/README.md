# you_model_i_model

# Instructions for running Backend

Before starting the backend, run `pip install -r requirements.txt` to install all required libraries.

If you got an error when installing Pytorch, try this command

```
pip install torch==1.12.1+cu116 torchvision==0.13.1+cu116 torchaudio==0.12.1 --extra-index-url https://download.pytorch.org/whl/cu116
```

To start the backend, run `python backend/run.py`

Do not go to the backend folder and start backend there!

# Instructions for running frontend

Before starting the frontend, run `npm install react-scripts` to install react.

To start the frontend, run `npm start` in the dashboard folder.
